# Chợ Công cụ Cộng đồng (Tool Hub)

**Tool Hub** là danh mục trực tuyến tích hợp sẵn, nơi người dùng có thể khám phá, cài đặt và gỡ bỏ các kỹ năng cộng đồng, máy chủ MCP và plugin tự động hóa chỉ bằng một cú nhấp chuột.

---

## 1. Duyệt Danh mục Công cụ

1. Bấm vào mục **Công cụ (Tools)** → **Tool Hub** trên menu bên trái.
2. Lọc công cụ theo các danh mục:
   - 🌐 **Web & Tìm kiếm** (Tavily, Brave Search, Puppeteer)
   - 📁 **Tệp & Phân tích Dữ liệu** (Pandas Runner, PDF Parser, CSV Analyzer)
   - 💻 **DevOps & Hạ tầng** (Kubernetes, AWS CLI, Docker Manager, Git Automation)
   - 💬 **Tin nhắn & Mạng xã hội** (Twitter/X Poster, Reddit Scraper, Telegram Notify)
   - 🔒 **Bảo mật & Mã hóa** (Quét lỗ hổng, kiểm tra chứng chỉ SSL)

---

## 2. Cài đặt 1-Click

1. Bấm vào công cụ bạn muốn cài (ví dụ: **Tavily AI Search**).
2. Xem mô tả, quyền hạn yêu cầu và các tham số.
3. Bấm nút màu vàng **Cài đặt Kỹ năng**.
4. Nhập API Key nếu được yêu cầu (hệ thống sẽ tự động lưu vào Két bảo mật).
5. ActonOS tải gói công cụ về `/data/skills/<slug>/` và kích hoạt ngay lập tức.
