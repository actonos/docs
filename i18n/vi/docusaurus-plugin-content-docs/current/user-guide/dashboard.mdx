# Dashboard

**Dashboard** là màn hình chính. Dùng để xem ActonOS có khỏe không, agent nào đang bận, và có việc nào chờ bạn phê duyệt.

Mở từ **Dashboard** trên thanh bên, hoặc nhấn **`Ctrl + K`** (`Cmd + K` trên macOS) rồi gõ `Dashboard`.

---

## Thanh trạng thái

Thanh trên cùng cập nhật khoảng hai giây một lần:

- **CPU** — tải bộ xử lý.
- **RAM** — bộ nhớ đang dùng / tổng (ví dụ `1.8 GB / 16 GB`).
- **Đĩa** — dung lượng trên volume `/data`.
- **Nhãn runtime** — `Bare-metal` hoặc `Docker`, tùy cách bạn cài.
- **Nhiệt độ** — chỉ trên máy bare-metal.

Nếu CPU hoặc đĩa cao lâu, xem [Vận hành trực tiếp](operations) và [Xử lý sự cố](../support-and-faq/troubleshooting).

---

## Thẻ agent

Mỗi agent đã đăng ký hiện một thẻ:

| Màu | Trạng thái | Ý nghĩa |
|:---|:---|:---|
| Xanh | Idle | Đang chờ chat, nhiệm vụ, hoặc nhịp heartbeat. |
| Vàng | Executing | Đang gọi một công cụ. |
| Tím | Delegated | Đang phối hợp với agent con. |
| Đỏ | Cần phê duyệt | Dừng cho đến khi bạn duyệt hoặc từ chối. |

Bấm thẻ để mở Chat với agent đó, hoặc nhảy sang cấu hình trong [Agent Studio](agent-studio).

---

## Bảng lệnh (`Ctrl + K`)

Từ bất kỳ trang nào, nhấn **`Ctrl + K`** (`Cmd + K` trên macOS) để:

- Nhảy tới Chat, Nhiệm vụ, Plugins, Skills, Cài đặt, hoặc Terminal.
- Bắt đầu chat bằng cách gõ tên agent.
- Mở tệp Workspace mà không phải duyệt thư mục.
- Kích hoạt **Sao lưu hệ thống**, **Pulse heartbeat**, hoặc **Khóa phiên**.

---

## Phê duyệt

Khi agent thử việc nhạy cảm (sửa file hệ thống, chạy lệnh lạ, gửi email hàng loạt), banner màu hổ phách hiện trên dashboard:

1. Đọc tên công cụ, đích, và tham số.
2. Bấm **Approve** để chạy tiếp đúng điểm dừng (có thể ghi lý do vào nhật ký).
3. Bấm **Reject** để hủy hành động đó.

Bạn cũng xem phê duyệt ở [Thông báo](notifications) và [Vận hành trực tiếp](operations).
