# Web Terminal

**Web Terminal** là shell dòng lệnh trong trình duyệt. Dùng cho `git`, `htop`, editor, kiểm tra nhanh. Nhật ký agent nằm ở [Vận hành trực tiếp](operations); trang này để **bạn** gõ lệnh.

Mở **Terminal** trên thanh bên.

---

## Bạn làm được gì

- xterm đủ màu (vim, nano, htop, tmux, git).
- Copy/paste từ menu chuột phải.
- Lịch sử lệnh giữ qua lần tải lại trang.

Tệp Workspace dùng được theo tên gốc (ví dụ `report.pdf` qua `user-workspace/`).

---

## Giới hạn (không phải root trên máy chủ)

Lệnh không chạy root trên máy:

**Bare-metal**

- Cách ly bằng Bubblewrap và cgroups.
- `/usr`, `/lib`, `/bin` chỉ đọc.
- Vùng ghi được là scratchpad agent và Workspace của bạn.
- Trần: **512 MB RAM**, **50% CPU**, **30 tiến trình**.

**Docker**

- User không root `acton` (UID 1000) trong subshell hạn chế.

Nếu lệnh bị chặn, đó là sandbox, không phải terminal hỏng. Nhờ agent làm việc trong Workspace, hoặc đổi yêu cầu.
