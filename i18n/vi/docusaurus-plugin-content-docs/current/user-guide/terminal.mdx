# Web Terminal & Dòng Lệnh Sandboxed

**Web Terminal** cung cấp một cửa sổ dòng lệnh tương tác an toàn trực tiếp trên trình duyệt web.

---

## 1. Cơ chế Cách ly An toàn Sandbox

Mọi câu lệnh chạy trong terminal đều được kiểm soát nghiêm ngặt:

### Trên MiniPC Bare-Metal:
- Chạy qua **Bubblewrap (`bwrap`)** và Linux **Cgroups v2**.
- Các thư mục hệ thống (`/usr`, `/lib`, `/bin`) được gắn kết ở chế độ **Chỉ Đọc (Read-Only)**.
- Vùng được phép ghi gồm thư mục tạm của agent và tài liệu **Workspace** của bạn, mở được theo tên gốc (ví dụ `report.pdf` trong `user-workspace/`).
- Giới hạn cứng: **512 MB RAM**, **50% CPU** và tối đa **30 tiến trình đồng thời**.

### Trên Docker Container:
- Chạy dưới quyền user không có root `acton` (UID 1000) trong môi trường subshell jail.

---

## 2. Tính năng Hỗ trợ

- Hỗ trợ màu sắc ANSI đầy đủ, tương thích các công cụ dòng lệnh như `htop`, `vim`, `nano`, `git`.
- Tự động lưu lịch sử lệnh giữa các lần tải lại trang.
