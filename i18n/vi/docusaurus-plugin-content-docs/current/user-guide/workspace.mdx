# Workspace

**Workspace** là thư mục tài liệu của bạn trong ActonOS. Tải tệp lên, nhờ agent ghi, mở trong editor có sẵn, hoặc gửi sang Telegram. Tên giữ nguyên: `report.pdf` vẫn là `report.pdf`.

---

## Mở và sửa tệp

Workspace có viewer cho các loại phổ biến:

- Editor mã (tô cú pháp nhiều ngôn ngữ)
- Xem trước Markdown
- Cây JSON
- Bảng CSV / TSV
- Ảnh, âm thanh, video, PDF

Tải lên hoặc tải xuống, xuất chọn lọc thành `.zip`, chuột phải để đổi tên, nhân bản, di chuyển, xóa. Thanh thống kê hiện dung lượng đang dùng.

---

## Tên bạn nói ra được

Khi bạn tải `report.pdf` hoặc nhờ agent lưu `weekly-notes.md`, đó là tên trên trang — và tên agent dùng:

- “Tóm tắt `report.pdf` trong workspace.”
- “Lưu cái này thành `weekly-notes.md`.”
- “Mở PDF tôi tải hôm qua và trích bảng.”

Bạn không bao giờ truyền ID lưu trữ nội bộ.

:::tip Workspace và scratchpad
**Workspace** là của bạn. Tệp ở đây đến khi bạn xóa.

Agent còn **scratchpad riêng** cho script tạm. Những tệp đó **không** hiện ở đây cho đến khi agent **xuất bản** (ví dụ: “lưu PDF này vào workspace của tôi”).
:::

### Mở PDF từ script

1. Tải `report.pdf`, hoặc nhờ agent lưu.
2. Nhờ: “Trích trang đầu của `report.pdf`.”
3. Agent mở đúng tên đó (PDF, ảnh, ZIP, Word, Excel…). Tệp không bị dồn thành text chat trước, nên font còn nguyên.

### Lưu kết quả lại

- “Viết tóm tắt vào `go_126_summary.md` trong workspace.”
- “Tạo `invoice.pdf` và lưu vào workspace của tôi.”

Rồi tải từ Workspace, hoặc [gửi tệp sang app chat](channels#sending-files-to-chat).

## Tìm trong tệp của bạn

Văn bản, Markdown và mã nguồn được lập chỉ mục tự động để agent tìm sau.

- Sửa liên tục chờ khoảng một phút mới index lại, tránh lãng phí.
- Bấm **Reindex Semantic Memory** nếu tệp mới chưa tìm thấy.

Cách index hoạt động: [Hybrid Memory](../advanced-architecture/hybrid-memory-rag).
