# Agent Studio

**Agent Studio** là nơi bạn tạo agent: tên, tính cách, mô hình, công cụ, và (nếu muốn) swarm agent con.

Mở **Agents** trên thanh bên, hoặc nhấn **`Ctrl + K`** rồi gõ `Create Agent`.

---

## Tạo agent

1. Bấm **+ New Agent**.
2. Điền danh tính:
   - **Tên** — hiện trong Chat (ví dụ `Research Assistant`).
   - **Slug** — id ổn định (ví dụ `research-bot`).
   - **Mô tả** — vai trò ngắn, hữu ích cho bạn và cho agent khác trong swarm.
3. Viết **system prompt** nêu việc cần làm và giới hạn.
4. Chọn mô hình, công cụ, mức phê duyệt.
5. Bấm **Save Agent Manifest**.

Prompt thực tế trông như sau:

```markdown
# Vai trò
Bạn là trợ lý nghiên cứu trên ActonOS.
Tìm nguồn, kiểm tra sự thật, viết tóm tắt Markdown rõ ràng.

# Giới hạn
1. Ưu tiên tệp Workspace mà người dùng đã đặt tên (ví dụ go_126_summary.md).
2. Xin phê duyệt trước khi restart dịch vụ hoặc xóa tệp.
3. Nếu tìm kiếm thất bại, nói thật thay vì đoán.
```

:::tip Biến trong prompt
Bạn có thể chèn:

- `{{system.time}}` — giờ và múi giờ hiện tại
- `{{system.runtime_mode}}` — `baremetal` hoặc `docker`
- `{{workspace.root}}` — đường dẫn Workspace
:::

## Mô hình

ActonOS gọi **mô hình chính** trước. Nếu bị giới hạn tốc độ hoặc lỗi, nó chuyển sang fallback.

| Mục | Việc nó làm | Giá trị điển hình |
|:---|:---|:---|
| Mô hình chính | Suy luận hàng ngày | `anthropic:claude-3-7-sonnet` |
| Fallback 1 | Khi mô hình chính lỗi | `openai:gpt-4o` |
| Fallback 2 | Rẻ hoặc chạy local | `ollama:qwen2.5-coder` |
| Temperature | `0` chặt, `1` sáng tạo hơn | `0.2` cho code và phân tích |
| Max tokens | Trần mỗi bước trả lời | `4096` |

## Công cụ và an toàn

Chỉ giao công cụ agent thật sự cần:

- `*` — mọi công cụ đã cài
- `native_*` — chỉ công cụ dựng sẵn
- `mcp_github_*` — chỉ công cụ MCP GitHub

**Mức phê duyệt:**

| Mức | Hành vi |
|:---|:---|
| Low | Công cụ được phép chạy không hỏi. |
| Medium | Ghi Workspace được chạy. Shell, xóa, cron, đổi extension vẫn cần bạn. |
| High | Xác nhận mọi hành động nhạy cảm. |

Ngoài ra:

- **Đường dẫn Workspace cho phép** — ví dụ `docs/*` và `reports/*`.
- **Ngân sách vòng lặp** — số bước suy luận tối đa mỗi việc (mặc định `25`).

## Swarm (tùy chọn)

Agent cha có thể giao việc cho chuyên gia:

1. Mở **Swarm & Delegation**.
2. Bật **Enable Agent Delegation**.
3. Chọn agent con được phép (ví dụ `Researcher` và `Code Writer`).
4. Đặt **delegation budget** (độ sâu gọi lồng, ví dụ `3`).

Agent cha vẫn giữ mục tiêu; con chạy bước của mình trong sandbox rồi trả kết quả.
