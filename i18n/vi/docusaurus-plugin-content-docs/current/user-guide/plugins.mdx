# Plugins

Plugin thêm năng lực cho ActonOS mà không cần khởi động lại. Một plugin có thể là:

- **công cụ** agent gọi được (thời tiết, tạo ảnh, API nội bộ)
- **kênh** nối Telegram, Discord, Slack, WhatsApp hoặc Zalo
- **connector** nói chuyện với GitHub, Notion, Google Workspace…

Bạn cài ở **Extensions → Plugins**. Nếu muốn **tự viết**, vào [Plugin SDK](../plugin-sdk/overview).

---

## Cài plugin

ActonOS nhận:

- **`.actonpkg`** — gói chuẩn (`manifest.json` + `plugin.wasm` + chữ ký và README tùy chọn)
- **`.wasm`** — file WebAssembly thô

Các bước:

1. Mở **Extensions → Plugins**.
2. Bấm **+ Upload Plugin**.
3. Thả tệp, hoặc chọn từ máy.
4. Đọc tóm tắt quyền:
   - website nào được gọi
   - bí mật vault nào được đọc
   - có được kho lưu trữ riêng nhỏ không
5. Bấm **Install & Activate**.

Plugin chạy ngay. Không reboot ActonOS.

:::tip Gói chính thức
Kênh chat và connector đi kèm ActonOS. Sau khi cập nhật OS, tải lại `.actonpkg` mới nhất để gửi tệp và API còn khớp. Xem [plugin chính thức](../plugin-sdk/official-plugins).
:::

## Cấu hình

Nếu plugin khai báo settings, **Configure** mở form tự sinh:

- Trường được nhóm (General, Bot Accounts…).
- Token đánh dấu secret vào **vault mã hóa**, không phải file cấu hình nhìn thấy được.
- Plugin chat cho phép **nhiều tài khoản bot**, mỗi cái gắn một agent.

Lưu form. Plugin nạp lại settings; agent khác vẫn chạy.

---

## Nhật ký

Trên thẻ plugin, mở **View Logs** (hoặc tab **Logs**):

- dòng `[INFO]`, `[WARN]`, `[DEBUG]`, `[ERROR]` kèm timestamp
- bộ nhớ plugin đang dùng
- HTTP ra ngoài nó đã thử

Nếu Telegram “gửi thành công” mà chat không thấy gì, hãy xem log trước.

---

## Bật, tắt, gỡ

| Thao tác | Hiệu lực |
|:---|:---|
| Disable | Tạm dừng plugin, ẩn công cụ. Config và bí mật còn. |
| Enable | Chạy lại ngay. |
| Uninstall | Dừng, hủy đăng ký, xóa `/data/plugins/{id}` và kho riêng. |

## Plugin kênh và tệp

Khi bạn nhờ agent gửi `report.pdf` sang Telegram (hoặc app khác), ActonOS **chỉ chuyển tệp** cho plugin kênh đã cài. Plugin tự upload lên app đó.

Nghĩa là:

1. App chat phải được cài như plugin. OS không có uploader Telegram ẩn.
2. Sau khi cập nhật ActonOS, cài lại plugin kênh cho khớp định dạng tệp hiện tại. Plugin cũ có thể báo thành công trong khi tệp không bao giờ hiện (đặc biệt Zalo), hoặc PDF mở ra font vỡ.

Để làm mới: **Uninstall**, rồi **Upload** `.actonpkg` chính thức mới nhất.

Phía người dùng: [Gửi tệp sang chat](channels#sending-files-to-chat). Tác giả plugin: [Plugin kênh](../plugin-sdk/channels#sending-files).
