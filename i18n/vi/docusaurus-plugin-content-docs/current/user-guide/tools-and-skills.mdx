# Công cụ và skill

Agent chỉ làm thêm việc khi bạn cấp **công cụ**. ActonOS có vài cách thêm. Không cần dùng hết.

| Loại | Khi nào dùng | Ở đâu |
|:---|:---|:---|
| Công cụ dựng sẵn | Tìm web, duyệt, tệp, shell, thông báo | Luôn có |
| Plugin | Công cụ tùy chỉnh, app chat, SaaS | [Plugins](plugins) |
| Máy chủ MCP | MCP bạn đã chạy sẵn | Cài đặt Tool / MCP |
| Skill | Thư mục `skill.json` + script | `/data/skills/<name>/` |

---

## Công cụ dựng sẵn

Đi kèm ActonOS:

- **Web** — `native_web_search`, `native_browser_navigate`, `native_browser_screenshot`
- **Tài liệu của bạn** — `native_workspace_search`, `native_workspace_read`, `native_workspace_write`, `native_workspace_delete`. Tệp giữ tên như `report.pdf`.
- **Scratchpad agent** — `native_file_read` / `native_file_write` cho script tạm. Những tệp này **không** hiện trên trang Workspace cho đến khi agent xuất bản.
- **Shell** — `native_exec` trong sandbox. Tệp Workspace có theo tên gốc dưới `user-workspace/` (`ACTONOS_USER_WORKSPACE`).
- **Thông báo chat** — `native_channel_notify` gửi text **hoặc tệp Workspace** qua plugin kênh đã cài. Chọn đúng một kênh khi đính tệp.

Bật công cụ theo từng agent trong [Agent Studio](agent-studio).

---

## Máy chủ MCP

Nếu bạn đã chạy MCP (stdio, HTTP hoặc SSE), thêm trong cài đặt MCP. ActonOS nói cùng giao thức. Biến môi trường bí mật lưu vault dưới `mcp.env.<id>`.

Chi tiết: [Tích hợp MCP](../developer-reference/mcp-integration).

---

## Plugin

Một `.actonpkg` có thể mang công cụ, kênh chat, connector SaaS, hoặc kết hợp. Cài từ [Plugins](plugins). Để viết, dùng [Plugin SDK](../plugin-sdk/overview).

---

## Skill dạng thư mục

Với công cụ script nhỏ, tạo:

```
/data/skills/my_custom_skill/
├── skill.json
└── run.sh          # hoặc run.py
```

ActonOS theo dõi thư mục đó. Thêm, sửa, xóa skill thì đăng ký lại không cần restart. Bạn cũng cài skill catalog từ [Tool Hub](tool-hub).

Định dạng: [Skill tùy chỉnh](../developer-reference/custom-skills-guide).
