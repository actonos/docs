# Công cụ và skill

Agent chỉ làm thêm việc khi bạn cấp **công cụ**. ActonOS có vài cách thêm. Không cần dùng hết.

| Loại | Khi nào dùng | Chỗ trên UI |
|:---|:---|:---|
| Công cụ dựng sẵn (native) | Tìm web, duyệt, tệp, shell, thông báo | **Extensions → Native Tools** |
| Máy chủ MCP | MCP bạn đã chạy sẵn | **Native Tools → Connect MCP** |
| Plugin | Công cụ tùy chỉnh, app chat, SaaS | [Plugins](plugins) |
| Skill | `skill.json` + script, hoặc skill cộng đồng | **Extensions → Skills** |

---

## Trang Native Tools

Mở **Extensions → Native Tools**. Trang này liệt kê **công cụ dựng sẵn** và **công cụ MCP** đã đăng ký. Skill có trang riêng, nên không hiện ở đây.

Bạn có thể:

- Lọc **All**, **Native**, hoặc **MCP**.
- Tìm theo tên hoặc mô tả.
- Bấm **Test** trên một công cụ để chạy một lần với tham số JSON.
- Bấm **Connect MCP** để thêm máy chủ (`stdio`, Streamable HTTP, hoặc SSE). Bí mật vào vault dưới `mcp.env.<id>`.
- Bật hoặc tắt máy chủ MCP đã nối mà không cần xóa.

Chi tiết: [Tích hợp MCP](../developer-reference/mcp-integration).

Bật từng công cụ theo agent trong [Agent Studio](agent-studio).

### Công cụ dựng sẵn

Đi kèm ActonOS:

- **Web** — `native_web_search`, `native_browser_navigate`, `native_browser_screenshot`
- **Tài liệu của bạn** — `native_workspace_search`, `native_workspace_read`, `native_workspace_write`, `native_workspace_delete`. Tệp giữ tên như `report.pdf`.
- **Scratchpad agent** — `native_file_read` / `native_file_write` cho script tạm. Những tệp này **không** hiện trên trang Workspace cho đến khi agent xuất bản.
- **Shell** — `native_exec` trong sandbox. Tệp Workspace có theo tên gốc dưới `user-workspace/` (`ACTONOS_USER_WORKSPACE`).
- **Thông báo chat** — `native_channel_notify` gửi text **hoặc tệp Workspace** qua plugin kênh đã cài. Chọn đúng một kênh khi đính tệp.

## Trang Skills

Mở **Extensions → Skills**.

- **Installed** — skill đã có trên máy. Bật/tắt, xem, hoặc gỡ.
- **Community Hub** — duyệt và cài gói skill cộng đồng một cú bấm.
- **Create Skill** — thêm skill thư mục từ giao diện.

Skill bạn tự viết trên đĩa:

```
/data/skills/my_custom_skill/
├── skill.json
└── run.sh          # hoặc run.py
```

ActonOS theo dõi thư mục đó. Thêm, sửa, xóa skill thì đăng ký lại không cần restart.

Định dạng: [Skill tùy chỉnh](../developer-reference/custom-skills-guide).

## Plugin

Một `.actonpkg` có thể mang công cụ, kênh chat, connector SaaS, hoặc kết hợp. Cài từ [Plugins](plugins). Để viết, dùng [Plugin SDK](../plugin-sdk/overview).
