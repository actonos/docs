# Tool Hub

**Tool Hub** là catalog trong ứng dụng. Duyệt skill cộng đồng và công cụ kiểu MCP, cài một cú bấm.

---

## Duyệt

1. Mở **Tools → Tool Hub**.
2. Lọc theo nhóm (Web & Search, Files & Data, DevOps, Messaging, Security) hoặc tìm theo tên, tác giả, tag.
3. Mở một mục để đọc mô tả, khóa cần thiết, và quyền.

---

## Cài

1. Bấm **Install Skill**.
2. Nếu cần khóa (ví dụ `TAVILY_API_KEY`), dán khi được hỏi. Lưu vào vault.
3. ActonOS tải gói vào `/data/skills/<slug>/` và đăng ký ngay.

Rồi bật skill đó trên agent sẽ dùng, trong [Agent Studio](agent-studio).

---

## Tắt hoặc gỡ

- **Disable** — giữ tệp và khóa, ẩn công cụ.
- **Uninstall** — xóa thư mục skill và khóa vault liên quan.

Với plugin WASM (kênh, connector, công cụ tùy chỉnh), dùng [Plugins](plugins) thay vì Tool Hub.
