# Kênh chat

**Channels** nối agent với Telegram, Discord, Slack, WhatsApp và Zalo. Mỗi app chat là một [plugin](plugins) đã cài. Người ta nhắn bot; agent được gán trả lời. Bạn cũng có thể nhờ agent gửi tệp Workspace vào chat đó.

---

## Thiết lập kênh

### 1. Cài plugin

1. Mở **Extensions → Plugins**.
2. Tải gói nếu chưa có (`channel-telegram.actonpkg`, `channel-discord.actonpkg`…).

### 2. Thêm tài khoản bot

1. Trên thẻ plugin, bấm **Configure**.
2. Trong **Bot Accounts**, bấm **+ Add Account**.
3. Điền:
   - **Account ID** — id ngắn như `tg_dev_bot` (chữ thường, số, `_` hoặc `-`).
   - **Bot token** — từ [@BotFather](https://t.me/botfather) hoặc Discord Developer Portal.
   - **Default agent** — ai trả lời tin đến.
   - **Listen target** — tùy chọn: chỉ nhóm/kênh này.
   - Công tắc typing, reaction xác nhận, quote-reply (mặc định bật).
4. Bấm **Save Changes**. Token vào vault mã hóa. Plugin nạp lại ngay.

Bạn có thể chạy nhiều bot trên cùng một app (ví dụ bot hỗ trợ và bot vận hành).

---

## PIN ghép cặp (tin đầu tiên)

Lần đầu một người lạ nhắn bot:

1. Bot trả **PIN 6 số** dùng một lần.
2. Trong ActonOS, mở **Settings** (hoặc hộp Pairing).
3. Nhập PIN để ủy quyền người đó.
4. Tin sau từ người đó đi thẳng tới agent.

Chưa ghép cặp thì bot không chạy công cụ agent cho người gửi đó.

---

## Sức khỏe

Thẻ plugin và Operations hiện:

- Xanh **Connected**
- Vàng **Reconnecting**
- Đỏ **Error** (token thu hồi, rate limit, mạng)

Socket rớt thì ActonOS thử lại với backoff. Lỗi kéo dài cũng vào [Thông báo](notifications). Mở **Logs** trên thẻ plugin để thấy lỗi cụ thể.

## Gửi tệp sang chat {#sending-files-to-chat}

Đặt tệp vào [Workspace](workspace) trước, rồi nhờ.

**Trong Chat ActonOS:**

```
Gửi report.pdf từ workspace sang nhóm Telegram.
```

**Trên Telegram, Discord hoặc Zalo, nhắn bot:**

```
Gửi file report.pdf sang đây.
```

Điều gì xảy ra:

1. Agent tìm tệp theo tên gốc.
2. ActonOS giao byte cho **plugin kênh đã cài**.
3. Plugin upload bằng API của app chat.

OS lõi không nói chuyện với Telegram hay Zalo. Nếu gửi thất bại, mở **Plugins → thẻ kênh → Logs**.

:::note Một app chat mỗi lần
Khi đính tệp, chọn **một** kênh đã cài (ví dụ Telegram). Gửi một tệp tới “mọi kênh” không được hỗ trợ.
:::

### Người nhận thấy gì

| App | Tới nơi là |
|:---|:---|
| Telegram, Discord, Slack, WhatsApp | Tệp bình thường, giữ tên (`report.pdf`). |
| Zalo | Tệp bot đăng qua JSON API của Zalo (URL HTTPS công khai, hoặc tệp nhỏ mã hóa trong request). Zalo không dùng multipart kiểu Telegram. |

### Giữ plugin mới

Sau khi cập nhật ActonOS, cài lại `.actonpkg` kênh mới nhất. Plugin cũ có thể:

- Báo đã gửi trong khi chat không thấy gì (hay gặp trên Zalo).
- Gửi PDF **font vỡ** (byte bị hỏng lúc chuyển).

Dùng gói chính thức trong [Plugin chính thức](../plugin-sdk/official-plugins).
