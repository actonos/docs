# Thông báo

**Notification Center** liệt kê sự kiện cần bạn nhìn: phê duyệt, nhiệm vụ xong, tích hợp đứt, lỗi hệ thống.

Mở **Notifications** trên thanh bên.

---

## Các loại

| Loại | Nhãn | Việc cần làm |
|:---|:---|:---|
| Cần phê duyệt | Cam | Mở ra, duyệt hoặc từ chối. |
| Mốc nhiệm vụ | Xanh | Nhiệm vụ hoặc tự động hóa đã xong. |
| Cảnh báo tích hợp | Vàng | Bot chat hoặc token OAuth rớt; kết nối lại nếu vẫn đỏ. |
| Lỗi hệ thống | Đỏ | Đĩa, sandbox, hoặc daemon — xem [Xử lý sự cố](../support-and-faq/troubleshooting). |
| Info | Xanh dương | Sao lưu xong, có bản OTA, tương tự. |

---

## Push trên trình duyệt

Để nhận cảnh báo khi tab ActonOS đã đóng:

1. Mở **Notifications**.
2. Bấm **Enable Browser Push Notifications**.
3. Bấm **Allow** trên hộp trình duyệt.

Phê duyệt và cảnh báo ưu tiên cao sẽ hiện như thông báo hệ điều hành trên máy hoặc điện thoại.

---

## Dọn hộp thư

- Lọc: Tất cả, Chưa đọc, Phê duyệt, Lỗi.
- Đánh dấu một mục đã đọc, hoặc **Mark All as Read**.
- **Clear History** xóa cảnh báo cũ.
