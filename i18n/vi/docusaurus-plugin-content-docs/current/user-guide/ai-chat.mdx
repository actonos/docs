# Chat

**Chat** là nơi bạn nói chuyện với agent. Bạn có thể đính tài liệu và ảnh, xem công cụ chạy trực tiếp, nhờ agent lưu vào [Workspace](workspace) hoặc gửi tệp qua app chat đã nối.

---

## Bắt đầu hội thoại

1. Mở **Chat** trên thanh bên.
2. Bấm **+ New Chat** trên danh sách hội thoại.
3. Chọn agent (ví dụ `General Assistant` hoặc `Research Agent`).
4. Gõ tin và nhấn **Enter**. Dùng **Shift + Enter** để xuống dòng.

:::tip Chưa có agent?
Tạo trong [Agent Studio](agent-studio), hoặc làm [hướng dẫn 5 phút](../getting-started/quickstart-tutorial).
:::

---

## Đính tệp và ảnh

Bấm biểu tượng kẹp giấy, hoặc kéo thả vào cửa sổ chat.

| Loại | Định dạng | Hệ thống làm gì |
|:---|:---|:---|
| Văn bản và mã | `.txt`, `.md`, `.py`, `.go`, `.js`, `.ts`, `.json`, `.yaml`, `.sql` | Đọc như text. |
| Tài liệu | `.pdf`, `.docx`, `.doc` | Chuyển sang Markdown, có đánh dấu trang. |
| Bảng tính | `.csv`, `.tsv`, `.xlsx`, `.xls` | Chuyển thành bảng Markdown. |
| Ảnh | `.png`, `.jpg`, `.jpeg`, `.webp`, `.svg` | Chuẩn bị cho mô hình có vision. |

Tệp đính trong chat thuộc **hội thoại này**. Để giữ lâu, nói:

```
Lưu cái này thành brief.pdf trong workspace.
```

Tệp Workspace giữ nguyên tên, nên sau này bạn nói “Mở `brief.pdf`” hoặc “Gửi `brief.pdf` sang Telegram.”

---

## Xem công cụ chạy

Khi agent tìm web, chạy script, hoặc ghi tệp, một **thẻ công cụ** hiện trên dòng thời gian. Mở ra để xem tham số, thời gian, kết quả.

Bạn không cần hiểu tên công cụ. Nếu lỗi, thẻ hiện thông báo; bạn diễn đạt lại yêu cầu hoặc duyệt việc đang dừng từ [Dashboard](dashboard).

---

## Gửi tệp Workspace sang app chat

Nếu đã cài Telegram, Discord, Slack, WhatsApp hoặc Zalo, hãy nói trong Chat:

```
Gửi report.pdf từ workspace sang Telegram.
```

Agent tìm tệp theo tên rồi giao cho plugin kênh đó. Xem [Gửi tệp sang chat](channels#sending-files-to-chat).
