# Connectors

**Connectors** cho agent dùng app đám mây (GitHub, Google Workspace, Notion, Slack, Linear, Jira, Figma) mà bạn không dán mật khẩu dài vào chat. Mỗi connector là một [plugin](plugins). Đăng nhập dùng **OAuth 2.1** (hoặc API key / bearer, tùy app). Token nằm trong vault.

---

## Sau khi kết nối bạn được gì

Khi connector xanh **Connected**, các action trở thành công cụ agent gọi được — nếu bạn cấp chúng trong [Agent Studio](agent-studio).

| Plugin | Agent có thể… |
|:---|:---|
| Google Workspace | Tìm Gmail, tạo sự kiện lịch, liệt kê Drive, đọc Docs. |
| GitHub | Liệt kê repo, đọc/tạo issue, mở pull request, tìm code. |
| Notion | Tìm trang, tạo trang, truy vấn database. |
| Slack | Đăng tin, liệt kê kênh, đọc lịch sử. |
| Linear | Liệt kê, tạo, cập nhật issue. |
| Jira Cloud | Tìm bằng JQL, tạo issue, chuyển trạng thái. |
| Figma | Đọc file và comment, đăng comment. |

Tên công cụ đầy đủ nằm ở [Plugin chính thức](../plugin-sdk/official-plugins).

---

## Kết nối tài khoản

1. Mở **Extensions → Plugins**.
2. Mở connector (ví dụ **GitHub**) rồi bấm **Configure**.
3. Nhập **Client ID** và **Client Secret** nếu plugin hỏi. Giá trị vào vault.
4. Bấm **Connect Account** và duyệt quyền trên trang nhà cung cấp.
5. Khi popup đóng, nhãn chuyển **Connected**.

ActonOS làm mới access token ở nền. Nếu bạn thu hồi quyền trên GitHub/Google, connector đỏ **Re-authentication required** và bạn nhận [thông báo](notifications).

---

## Dùng từ Chat

Cấp công cụ connector cho agent, rồi nói:

```
Liệt kê repo GitHub của tôi và mở issue "Docs review" trong actonos/docs.
```

Agent gọi công cụ connector; bạn vẫn có thể thấy hộp duyệt nếu mức phê duyệt là Medium hoặc High.
