# Tích hợp Máy chủ MCP (Model Context Protocol)

ActonOS hỗ trợ tích hợp các máy chủ **Model Context Protocol (MCP)** chuẩn hóa qua cả giao thức `stdio` cục bộ và `http`/`sse` từ xa.

---

## 1. Cấu hình Máy chủ MCP

Đăng ký máy chủ từ trang Công cụ hoặc qua `POST /api/tools/mcp`. Cấu hình lưu trong cơ sở dữ liệu ActonOS (không phải tệp JSON trên đĩa). Kết nối hoặc ngắt MCP có thể trả về `202 Accepted` cho đến khi người vận hành phê duyệt.

```json
{
  "id": "github-mcp",
  "name": "GitHub MCP",
  "transport": "stdio",
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-github"],
  "enabled": true
}
```

Với tài liệu Workspace, hãy dùng công cụ có sẵn `native_workspace_*`. Chúng giữ tên gốc. Đừng trỏ máy chủ filesystem MCP vào `/data/workspace` — thư mục đó lưu mã nội bộ, không phải tên bạn thấy trên trang Workspace.

Hỗ trợ hai transport:
- **`stdio`**: Daemon khởi chạy tiến trình MCP và nói chuyện qua stdin/stdout JSON-RPC.
- **`http` / `sse`**: Kết nối máy chủ MCP từ xa.
