# Phát triển plugin WebAssembly

Phần viết plugin giờ có mục riêng: **[Plugin SDK](../plugin-sdk/overview)**.

Hãy bắt đầu từ đó thay vì trang này. SDK (`github.com/actonos/plugin-sdk`, CLI `acton-plugin`) là cách được hỗ trợ để dựng tool, kênh chat và connector SaaS.

| Bạn muốn… | Mở |
|:---|:---|
| Hiểu mô hình | [Tổng quan Plugin SDK](../plugin-sdk/overview) |
| Scaffold, build, test, pack | [Plugin đầu tiên](../plugin-sdk/first-plugin) |
| Viết tool / kênh / connector | [Công cụ](../plugin-sdk/tools) · [Kênh](../plugin-sdk/channels) · [Connector](../plugin-sdk/connectors) |
| `manifest.json` và quyền | [Manifest](../plugin-sdk/manifest) |
| Cờ CLI | [Tra cứu CLI](../plugin-sdk/cli-reference) |
| Import và export host | [Host ABI](../plugin-sdk/host-abi) |
| Cài gói với tư cách người vận hành | [Plugins](../user-guide/plugins) |

Trang này được giữ để liên kết cũ không gãy.
