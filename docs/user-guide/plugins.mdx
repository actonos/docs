# Plugins

Plugins add extra abilities to ActonOS without restarting it. A plugin can be:

- a **tool** the agent can call (weather, image generation, a private API)
- a **channel** that connects Telegram, Discord, Slack, WhatsApp, or Zalo
- a **connector** that talks to GitHub, Notion, Google Workspace, and similar apps

You install them on **Extensions → Plugins**. If you want to **build** one, go to the [Plugin SDK](../plugin-sdk/overview).

---

## Install a plugin

ActonOS accepts:

- **`.actonpkg`** — the usual bundle (`manifest.json` + `plugin.wasm` + optional signature and README)
- **`.wasm`** — a raw WebAssembly file

Steps:

1. Open **Extensions → Plugins**.
2. Click **+ Upload Plugin**.
3. Drop the file, or browse for it.
4. Read the permission summary:
   - which websites it may call
   - which vault secrets it may read
   - whether it gets its own small storage
5. Click **Install & Activate**.

The plugin starts immediately. You do not reboot ActonOS.

:::tip Official packages
Channel and connector packages ship with ActonOS. After an OS update, re-upload the latest `.actonpkg` so file sending and APIs stay in sync. See [official plugins](../plugin-sdk/official-plugins).
:::

## Configure it

If the plugin declares settings, **Configure** opens a generated form:

- Fields are grouped (General, Bot Accounts, and so on).
- Tokens marked as secrets go into the **encrypted vault**, not a visible config file.
- Chat plugins let you add **several bot accounts** and bind each one to an agent.

Save the form. The plugin reloads with the new settings; other agents keep running.

---

## Logs

On the plugin card, open **View Logs** (or the **Logs** tab):

- `[INFO]`, `[WARN]`, `[DEBUG]`, `[ERROR]` lines with timestamps
- how much memory the plugin is using
- outbound HTTP calls it attempted

If a Telegram send “succeeds” but nothing appears in the chat, the log is the first place to look.

---

## Enable, disable, uninstall

| Action | Effect |
|:---|:---|
| Disable | Pauses the plugin and hides its tools. Config and secrets stay. |
| Enable | Starts it again immediately. |
| Uninstall | Stops it, unregisters tools/channels, deletes `/data/plugins/{id}` and its private storage. |

## Channel plugins and files

When you ask an agent to send `report.pdf` to Telegram (or another chat), ActonOS **only forwards the file** to the installed channel plugin. The plugin uploads it to that app.

That means:

1. The chat app must be installed as a plugin. There is no hidden Telegram uploader inside the OS.
2. After an ActonOS update, re-install channel plugins so they match the current file format. Older plugins may report success while the file never appears (especially on Zalo), or a PDF may open with broken fonts.

To refresh: **Uninstall**, then **Upload** the latest official `.actonpkg`.

From the user’s side, see [Sending files to chat](channels#sending-files-to-chat). Plugin authors, see [Channel plugins](../plugin-sdk/channels#sending-files).
