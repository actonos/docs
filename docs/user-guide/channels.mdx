# Channels

**Channels** connect your agents to Telegram, Discord, Slack, WhatsApp, and Zalo. Each chat app is an installed [plugin](plugins). People message the bot; the assigned agent replies. You can also ask an agent to send a Workspace file into that chat.

---

## Set up a channel

### 1. Install the plugin

1. Open **Extensions → Plugins**.
2. Upload the package if it is not already there (`channel-telegram.actonpkg`, `channel-discord.actonpkg`, and so on).

### 2. Add a bot account

1. On the plugin card, click **Configure**.
2. Under **Bot Accounts**, click **+ Add Account**.
3. Fill in:
   - **Account ID** — a short id such as `tg_dev_bot` (lowercase, digits, `_` or `-`).
   - **Bot token** — from [@BotFather](https://t.me/botfather) or the Discord Developer Portal.
   - **Default agent** — who answers incoming messages.
   - **Listen target** — optional: only this group or channel.
   - Typing, ack reaction, and quote-reply toggles (on by default).
4. Click **Save Changes**. The token is stored in the encrypted vault. The plugin reloads at once.

You can run several bots on the same app (for example a support bot and an ops bot).

---

## Pairing PIN (first message)

The first time a new person messages the bot:

1. The bot replies with a one-time **6-digit PIN**.
2. In ActonOS, open **Settings** (or the Pairing dialog).
3. Enter the PIN to authorize that user.
4. Later messages from that person go straight to the agent.

Until pairing succeeds, the bot will not run agent tools for that sender.

---

## Health

The plugin card and Operations show:

- Green **Connected**
- Yellow **Reconnecting**
- Red **Error** (revoked token, rate limit, network)

If a socket drops, ActonOS retries with backoff. Persistent failures also appear in [Notifications](notifications). Open **Logs** on the plugin card for the exact error.

## Sending files to chat {#sending-files-to-chat}

Put the file in [Workspace](workspace) first, then ask.

**In ActonOS Chat:**

```
Send report.pdf from the workspace to the Telegram group.
```

**In Telegram, Discord, or Zalo, to the bot:**

```
Gửi file report.pdf sang đây.
```

What happens:

1. The agent finds the file by its original name.
2. ActonOS hands the bytes to the **installed channel plugin**.
3. That plugin uploads the file with the chat app’s own API.

The core OS does not talk to Telegram or Zalo itself. If sending fails, open **Plugins → the channel card → Logs**.

:::note One chat app at a time
When attaching a file, pick a **specific** installed channel (for example Telegram). Sending a file to “all channels” is not supported.
:::

### What the recipient sees

| App | What arrives |
|:---|:---|
| Telegram, Discord, Slack, WhatsApp | A normal file with the original name (`report.pdf`). |
| Zalo | A file the bot posts through Zalo’s JSON API (a public HTTPS URL, or a small file encoded in the request). Zalo does not use Telegram-style multipart uploads. |

### Keep plugins up to date

After you update ActonOS, re-install the latest channel `.actonpkg`. Older plugins may:

- Say the file was sent while nothing appears (common on Zalo).
- Deliver a PDF with **broken fonts** (bytes were corrupted in transit).

Use the rebuilt official packages listed in [Official plugins](../plugin-sdk/official-plugins).
