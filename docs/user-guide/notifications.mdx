# Notifications

The **Notification Center** lists events that need your eyes: approvals, finished missions, broken integrations, and system errors.

Open **Notifications** in the sidebar.

---

## Types

| Type | Badge | What to do |
|:---|:---|:---|
| Approval required | Orange | Open it and approve or reject the action. |
| Mission milestone | Green | The mission or automation finished. |
| Integration warning | Yellow | A chat bot or OAuth token dropped; reconnect if it stays red. |
| System error | Red | Disk, sandbox, or daemon problem — see [Troubleshooting](../support-and-faq/troubleshooting). |
| Info | Blue | Backup done, OTA update available, and similar. |

---

## Browser push

To get alerts when the ActonOS tab is closed:

1. Open **Notifications**.
2. Click **Enable Browser Push Notifications**.
3. Click **Allow** in the browser prompt.

High-priority approvals and warnings then appear as OS notifications on the desktop or phone.

---

## Inbox hygiene

- Filter: All, Unread, Approvals, Errors.
- Mark one item read, or **Mark All as Read**.
- **Clear History** removes old alerts.
