# Chat

**Chat** is the main place you talk to an agent. You can attach documents and images, watch tools run live, and ask the agent to save work into [Workspace](workspace) or send a file through a connected chat app.

---

## Start a conversation

1. Open **Chat** in the left sidebar.
2. Click **+ New Chat** in the conversation list.
3. Pick an agent from the selector (for example `General Assistant` or `Research Agent`).
4. Type a message and press **Enter**. Use **Shift + Enter** for a new line.

:::tip No agent yet?
Create one in [Agent Studio](agent-studio), or follow the [5-minute quickstart](../getting-started/quickstart-tutorial).
:::

---

## Attach files and images

Click the paperclip, or drag files onto the chat window.

| Kind | Formats | What happens |
|:---|:---|:---|
| Text and code | `.txt`, `.md`, `.py`, `.go`, `.js`, `.ts`, `.json`, `.yaml`, `.sql` | Read as text. |
| Documents | `.pdf`, `.docx`, `.doc` | Converted to Markdown with page markers. |
| Spreadsheets | `.csv`, `.tsv`, `.xlsx`, `.xls` | Converted to Markdown tables. |
| Images | `.png`, `.jpg`, `.jpeg`, `.webp`, `.svg` | Prepared for vision-capable models. |

Chat attachments belong to **this conversation**. To keep a file for later, say:

```
Save this as brief.pdf in the workspace.
```

Workspace files keep their original names, so you can later say “Open `brief.pdf`” or “Send `brief.pdf` to Telegram.”

---

## Watch tools run

When an agent searches the web, runs a script, or writes a file, a **tool card** appears in the timeline. Expand it to see the arguments, duration, and result.

You do not need to understand the tool name. If something fails, the card shows the error; you can rephrase the request or approve a paused action from the [Dashboard](dashboard).

---

## Send a Workspace file to a chat app

If Telegram, Discord, Slack, WhatsApp, or Zalo is installed, ask in Chat:

```
Send report.pdf from the workspace to Telegram.
```

The agent finds the file by name and hands it to that channel’s plugin. See [Sending files to chat](channels#sending-files-to-chat).
