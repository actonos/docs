# Workspace

**Workspace** is your document folder inside ActonOS. Upload a file, ask the agent to write one, open it in the built-in editor, or send it to Telegram. Names stay as you gave them: `report.pdf` is still `report.pdf`.

---

## Open and edit files

Workspace includes viewers for common types:

- Code editor (syntax highlighting for many languages)
- Markdown preview
- JSON tree
- CSV / TSV table
- Images, audio, video, and PDF

Upload or download files, export a selection as `.zip`, and right-click to rename, duplicate, move, or delete. The stats bar shows how much space you are using.

---

## Names you can say out loud

When you upload `report.pdf` or ask the agent to save `weekly-notes.md`, those are the names on the page — and the names the agent uses:

- “Summarize `report.pdf` in the workspace.”
- “Save this as `weekly-notes.md`.”
- “Open the PDF I uploaded yesterday and extract the table.”

You never pass internal storage IDs.

:::tip Workspace vs scratchpad
**Workspace** is yours. Files stay until you delete them.

The agent also has a **private scratchpad** for temporary scripts. Those files do **not** appear here until the agent **publishes** them (for example: “save this PDF to my workspace”).
:::

### Open a PDF from a script

1. Upload `report.pdf`, or ask the agent to save it.
2. Ask: “Extract the first page of `report.pdf`.”
3. The agent opens that name (PDF, image, ZIP, Word, Excel, and similar). The file is not flattened into chat first, so fonts stay intact.

### Save results back

- “Write a summary to `go_126_summary.md` in the workspace.”
- “Create `invoice.pdf` and save it to my workspace.”

Then download from Workspace, or [send the file to a chat app](channels#sending-files-to-chat).

## Search across your files

Text, Markdown, and source files are indexed automatically so agents can search them later.

- Edits wait about a minute before re-indexing, so rapid saves are not wasted.
- Click **Reindex Semantic Memory** if a new file is not found yet.

How the index works: [Hybrid Memory](../advanced-architecture/hybrid-memory-rag).
