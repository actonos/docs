# Connectors

**Connectors** let agents use cloud apps (GitHub, Google Workspace, Notion, Slack, Linear, Jira, Figma) without you pasting long-lived passwords into chat. Each connector is a [plugin](plugins). Sign-in uses **OAuth 2.1** (or an API key / bearer token, depending on the app). Tokens sit in the encrypted vault.

---

## What you get after connecting

Once a connector is green **Connected**, its actions become tools the agent can call — if you grant those tools in [Agent Studio](agent-studio).

| Plugin | Agents can… |
|:---|:---|
| Google Workspace | Search Gmail, create calendar events, list Drive files, read Docs. |
| GitHub | List repos, read/create issues, open pull requests, search code. |
| Notion | Search pages, create pages, query databases. |
| Slack | Post messages, list channels, read history. |
| Linear | List, create, and update issues. |
| Jira Cloud | Search with JQL, create issues, transition issues. |
| Figma | Read files and comments, post comments. |

Exact tool names are listed in [Official plugins](../plugin-sdk/official-plugins).

---

## Connect an account

1. Open **Extensions → Plugins**.
2. Open the connector (for example **GitHub**) and click **Configure**.
3. Enter the app’s **Client ID** and **Client Secret** if the plugin asks for them. Those values go into the vault.
4. Click **Connect Account** and approve the permissions on the provider’s site.
5. When the popup closes, the badge turns **Connected**.

ActonOS refreshes access tokens in the background. If you revoke access at GitHub/Google, the connector turns red **Re-authentication required** and you get a [notification](notifications).

---

## Use it from Chat

Grant the connector tools to an agent, then say:

```
List my GitHub repositories and open an issue titled "Docs review" in actonos/docs.
```

The agent calls the connector tool; you may still see an approval prompt if the agent’s approval level is Medium or High.
