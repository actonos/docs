# Dashboard

The **Dashboard** is the home screen. Use it to see whether ActonOS is healthy, which agents are busy, and whether anything is waiting for your approval.

Open it from **Dashboard** in the left sidebar, or press **`Ctrl + K`** (`Cmd + K` on macOS) and type `Dashboard`.

---

## Status bar

The top bar updates about every two seconds:

- **CPU** — processor load.
- **RAM** — memory in use versus total (for example `1.8 GB / 16 GB`).
- **Disk** — space used on the persistent `/data` volume.
- **Runtime badge** — `Bare-metal` or `Docker`, depending on how you installed ActonOS.
- **Temperature** — chip temperature, on bare-metal hardware only.

If CPU or disk stays high for a long time, check [Live Operations](operations) and [Troubleshooting](../support-and-faq/troubleshooting).

---

## Agent cards

Each registered agent appears as a card:

| Color | State | Meaning |
|:---|:---|:---|
| Green | Idle | Waiting for a chat, mission, or scheduled pulse. |
| Yellow | Executing | Calling a tool right now. |
| Purple | Delegated | Coordinating work with child agents. |
| Red | Approval required | Paused until you approve or reject an action. |

Click a card to open Chat with that agent, or jump to its settings in [Agent Studio](agent-studio).

---

## Command palette (`Ctrl + K`)

From any page, press **`Ctrl + K`** (`Cmd + K` on macOS) to:

- Jump to Chat, Missions, Plugins, Skills, Settings, or Terminal.
- Start a chat by typing an agent name.
- Open a Workspace file without browsing the folder tree.
- Trigger **System Backup**, a **Heartbeat Pulse**, or **Session Lock**.

---

## Approvals

When an agent tries something sensitive (editing system files, running an unknown shell command, sending a broad email), an amber banner appears on the dashboard:

1. Read the tool name, target, and arguments.
2. Click **Approve** to resume from the exact pause point (you can add a short reason for the audit log).
3. Click **Reject** to stop that action.

You can also review approvals from [Notifications](notifications) and [Live Operations](operations).
