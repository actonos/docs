# Web Terminal

The **Web Terminal** is a command-line shell in the browser. Use it for `git`, `htop`, editors, and quick checks. Agent logs belong on [Live Operations](operations); this page is for **you** typing commands.

Open **Terminal** in the sidebar.

---

## What you can do

- Full color xterm (vim, nano, htop, tmux, git).
- Copy and paste from the right-click menu.
- Command history kept across reloads.

Workspace files are available by original name (for example `report.pdf` via `user-workspace/`).

---

## Limits (this is not root on the host)

Commands do not run as root on the machine:

**Bare-metal**

- Isolated with Bubblewrap and cgroups.
- `/usr`, `/lib`, `/bin` are read-only.
- Writable areas are the agent scratchpad and your Workspace.
- Caps: **512 MB RAM**, **50% CPU**, **30 processes**.

**Docker**

- Non-root user `acton` (UID 1000) inside a restricted subshell.

If a command is blocked, that is the sandbox, not a broken terminal. Ask an agent to work in Workspace instead, or adjust the task.
