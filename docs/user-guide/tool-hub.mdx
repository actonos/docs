# Tool Hub

**Tool Hub** is the in-app catalog. Browse community skills and MCP-style tools and install them in one click.

---

## Browse

1. Open **Tools → Tool Hub**.
2. Filter by category (Web & Search, Files & Data, DevOps, Messaging, Security) or search by name, author, or tag.
3. Open an entry to read the description, required keys, and permissions.

---

## Install

1. Click **Install Skill**.
2. If a key is required (for example `TAVILY_API_KEY`), paste it when prompted. It is stored in the vault.
3. ActonOS downloads the package into `/data/skills/<slug>/` and registers it immediately.

Then enable that skill on the agents that should use it in [Agent Studio](agent-studio).

---

## Disable or remove

- **Disable** — keep files and keys, hide the tools.
- **Uninstall** — delete the skill folder and its vault keys.

For WASM plugins (channels, connectors, custom tools), use [Plugins](plugins) instead of Tool Hub.
