# WebAssembly (WASM) Plugin Development

ActonOS embeds the pure-Go **`wazero` WebAssembly runtime**, allowing developers to write high-performance, sandboxed plugins in Go, Rust, or C without requiring CGO or external host runtimes.

---

## 1. Writing a WASM Plugin in Go

```go
package main

import (
	"encoding/json"
	"os"
)

type Input struct {
	Text string `json:"text"`
}

type Output struct {
	WordCount int `json:"word_count"`
	CharCount int `json:"char_count"`
}

func main() {
	var input Input
	json.NewDecoder(os.Stdin).Decode(&input)

	output := Output{
		WordCount: len(splitWords(input.Text)),
		CharCount: len(input.Text),
	}

	json.NewEncoder(os.Stdout).Encode(output)
}

func splitWords(s string) []string {
	// simple word counting logic
	return []string{s}
}
```

---

## 2. Compiling to WebAssembly (WASI)

Compile the Go source file targeting WASI:

```bash
GOOS=wasip1 GOARCH=wasm go build -o word_counter.wasm main.go
```

---

## 3. Deploying into ActonOS

Copy the compiled `.wasm` binary into `/data/plugins/`:

```bash
cp word_counter.wasm /data/plugins/
```

ActonOS immediately recognizes the binary, validates the exported WASI memory signatures, and exposes the tool to all authorized agents with near-native execution performance.
